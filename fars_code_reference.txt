FARS 2015 PERSON FILE - CODE REFERENCE
======================================
Meaning of the numeric codes in the 30-column extract used in this project
(NHTSA Fatality Analysis Reporting System, person-level table for 2015,
Google BigQuery dataset nhtsa_traffic_fatalities).


SOURCES AND HOW TO READ THIS FILE
---------------------------------
- Codes come from the NHTSA FARS Analytical User's Manual (2015) and the
  data dictionary of the BigQuery table. Where a table was checked against
  the data, the labels are the ones that appear in the extract.
- A plus sign (+) marks entries that follow NHTSA's standard coding but were
  not separately cross-checked against the 2015 manual text. Confirm them
  there before relying on them for anything beyond this project.
- Codes are shown as they appear in the data. Leading zeros may be dropped
  (07 can appear as 7).
- Sections follow the column order of the extract. Columns with no codes
  are skipped (consecutive_number, person_number, timestamp_of_crash).
- vehicle_make has no table here because the list is very long. See the
  Make element (V9, printed page 233) of the FARS Analytical User's Manual.
- Text columns (school_bus_related, rollover, fire_occurrence, sex,
  police_reported_alcohol_involvement, alcohol_test_status1,
  police_reported_drug_involvement, drug_test_status) arrive as text labels
  in the BigQuery export, not as codes. The labels listed are the ones
  found in the data.

General coding rules from the manual:
- Unknown is always coded with 9s (9, 99, 999, ...).
- Not Applicable is coded with zeros, with a few exceptions (for example 8
  for ejection and 8888 for death time).
- None is coded 0, except for the alcohol test result.
- Rollover, Emergency Motor Vehicle Use and Fire Occurrence are coded 0
  even when nothing is known, so a 0 there can mean "no" or "not reported".

Codes such as 8, 9, 98, 99 and 996-999 usually mean Not Reported, Unknown or
None Given. They should be set to missing before any statistics are run. The
exact codes treated as missing in this project are listed in the last
section.

24-26. drug_test_type4, drug_test_type5, drug_test_type6
    Three slots for the drug results found in one person's test. The same
    codes apply to all three. A specific drug code (such as 239 or 600)
    falls inside its category range.
    000      Test Not Given (also fills an unused slot)
    001      Tested, No Drugs Found/Negative
    095      Not Reported
    100-295  Narcotic
    300-395  Depressant
    400-495  Stimulant
    500-595  Hallucinogen
    600-695  Cannabinoid
    700-795  Phencyclidine (PCP)
    800-895  Anabolic Steroid
    900-995  Inhalant
    996      Other Drug
    997      Tested for Drugs, Results Unknown
    998      Tested for Drugs, Drugs Found, Type Unknown/Positive
    999      Unknown If Tested
    Code 095 sits between 001 and 100 and belongs to no category range.
    In the rows inspected, 996 often follows a person's last identified drug
    code, with 0 filling the remaining slot (for example 600, 996, 0), so it
    can be a filler and not a separate drug. This project assigns a person
    with an identified Narcotic, Depressant, Stimulant or Cannabinoid result
    to that category even when 996 is also present, and uses "Other drug"
    only when no such category is found.
